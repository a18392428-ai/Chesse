# شطرنج أونلاين لعبة شطرنج ويب سهلة التشغيل ومناسبة للهواتف المحمولة، مع دعم: - تسجيل اسم اللاعب - إنشاء غرف جديدة - الانضمام لغرفة عبر كود - مراقبة الألعاب كـ مشاهد - دردشة داخل الغرفة - دعم تثبيت التطبيق على Android كـ PWA - لعب أونلاين عبر PeerJS (مباشر بين الأجهزة من خلال نفس الكود) ## التشغيل افتح المشروع في متصفحك، ثم اذهب إلى: - `index.html` لتسجيل الاسم - `menu.html` للوصول إلى القوائم ## ملاحظات مهمة - هذا المشروع يعتمد على PeerJS عبر الإنترنت، لذلك يحتاج كلا الطرفين إلى الوصول إلى الإنترنت. - الأفضل استخدامه عبر المتصفح على الهاتف أو الحاسوب، ثم تثبيت التطبيق من قائمة المتصفح. - لمشاهدة اللعبة أو اللعب يجب استخدام نفس كود الغرفة. ## الملفات الأساسية - `index.html` — شاشة تسجيل الاسم - `menu.html` — القائمة الرئيسية - `online-create.html` — إنشاء غرفة المضيف - `online-join.html` — انضمام لاعب - `online-spectate.html` — مشاهدة اللعبة - `manifest.json` — إعدادات التطبيق المحمول - `sw.js` — خدمة العمل offline ## التثبيت على Android في متصفح Chrome أو Edge على الهاتف: 1. افتح الرابط الخاص بالموقع. 2. اضغط زر القائمة في المتصفح. 3. اختر "Add to Home screen" أو "تثبيت التطبيق". 4. استخدم التطبيق من الشاشة الرئيسية. ## ملاحظات تطويرية - اللعبة الحالية تستخدم مكتبة `chess.js` للتحقق من الحركات والقوانين. - التواصل الفعلي يتم عبر `PeerJS` مع STUN من Google. - إذا كنت تريد نسخة احترافية أكثر، يمكن لاحقاً إضافة: - قاعدة بيانات حقيقية - نظام تسجيل دخول - بطولات/مستويات - مؤثرات صوتية - حسابات ودرجات - روبوت للاعب الفردي ## الإطلاق في الإنتاج لإطلاق المشروع على الإنترنت على موقع حقيقي، تحتاج إلى: - استضافة ثابتة مثل GitHub Pages / Netlify / Vercel / Firebase Hosting - اعتماد HTTPS لأن PWA و PeerJS يعملان بشكل أفضل مع HTTPS ## للمطورين إذا رغبت في توسيع اللعبة، أضف: - نظام توقيت لكل لاعب - تسجيل تاريخ الحركات - إعادة اللعب - عناصر واجهة أكثر احترافية - دعم اللغة الإنجليزية والعربية
